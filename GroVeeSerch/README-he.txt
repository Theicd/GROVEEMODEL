Grove Search Companion - מנוע חיפוש מקומי ל-GROVEEMODEL
======================================================

1. הרץ Start-GroveSearch.bat (או Run-Install.bat בפעם הראשונה)
2. ב-GROVEEMODEL לחץ תוספים - הסטטוס יהפוך לירוק

כתובת: http://127.0.0.1:7000
מבוסס OpenSERP (MIT) - Bing, DuckDuckGo ועוד.

הערה: ההפעלה פותחת חלון ממוזער ברקע. אפשר לסגור את חלון ההפעלה אחרי "Grove Search is running".
